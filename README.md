# Machine Learning in Education

Public course materials for Conrad Borchers's Spring 2027 course at Vanderbilt University.
Course code: LPO 7240. The Spring 2027 materials are in preparation.

## Course website

The static site lives in `docs/`. There is no build step and no package installation.

Enable GitHub Pages in this repository:
1. Open Settings → Pages.
2. Select **Deploy from a branch**.
3. Select branch **main**, folder **/docs**, then Save.
4. Use the published URL displayed by GitHub after deployment finishes.

Expected default project address: https://conradborchers.github.io/machine-learning-education/
This address is provisional until Pages is enabled. A configured account domain affects the final address.

Link the deployed course site from https://cborchers.com/.
An optional course subdomain requires domain verification and DNS configuration before adding a new CNAME.
The inherited `ml.willdoyle.us` CNAME has been removed.

## Public material

This repository holds the course website, syllabus overview, module outline, reading links,
and selected student materials released during the term. Submissions and grades belong in Brightspace.
The current branch excludes instructor notes, solutions, rubrics for internal grading, and legacy source files.

Keep instructor preparation in a separate private repository. Public branches and folders have public visibility.
Publish files through an explicit release manifest from the instructor workspace. Avoid mirroring a private repository here.

Planned problem sets

Problem sets will cover data preparation and baseline prediction, regularized models, validation and tuning, support vector machines, trees and ensembles, neural networks, and uncertainty.

Semester project

Choose an educational question and dataset. Define the prediction task, compare models, evaluate their limits, and communicate the results in a research paper with reproducible code. Progress check-ins will support the project throughout the term.

Machine Learning in Education

Predictive modeling through educational applications.

Conrad Borchers, Vanderbilt University. Planned software options: R and Python.

Spring 2027 materials are in preparation.

Overview

Develop a reproducible modeling workflow, compare methods, and explain what the results support. The course covers regularization, support vector machines, trees and ensembles, neural networks, and uncertainty.

Course work

Applied problem sets and a semester project connect model evaluation to an educational question. Brightspace holds announcements, submissions, grades, and feedback.
